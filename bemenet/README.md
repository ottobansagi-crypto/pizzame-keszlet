# bemenet/

Ide kerül a két friss nyers Wildom export (Jelentések / Készlet):

- egy **HU** export (~47 oszlop, Debrecen legyen az utolsó üzlet)
- egy **SK** export (Michalska (1) / Kolárska (2))

A fájlneveknek nem kell pontosnak lenniük – a script oszlopszám alapján
ismeri fel, melyik a HU és melyik az SK. Egyszerre pontosan egy HU és egy
SK fájl legyen itt.
